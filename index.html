Demande de suppression des données - Tedhkrty

Tedhkrty respecte vos droits concernant vos données personnelles.

Demande de suppression

Vous pouvez demander la suppression de tout ou partie de vos données personnelles en nous contactant :

  • Email : tedhkrty@gmail.com

Types de données concernées

  • Profil utilisateur (nom, numéro de téléphone)
  • Historique des réservations
  • Données de connexion

Conservation des données

Certaines données peuvent être conservées pendant une période limitée (obligations légales, comptabilité ou sécurité), puis supprimées définitivement.

Délai de traitement

Les demandes sont traitées dans un délai raisonnable.
